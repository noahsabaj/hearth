# Hearth Soft Render

[![License](https://img.shields.io/badge/license-MIT%2FApache-blue.svg)](https://github.com/noahsabaj/hearth#license)

Draws Hearth's 2D scenes on the CPU, into a framebuffer for each window. Enable it with the `2d_soft` profile in place of `2d`, and add `ui_api` to draw UI with it.
